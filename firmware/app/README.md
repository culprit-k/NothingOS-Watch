# NothingOS Wear embedded application

This directory contains the first original Actions/Zephyr + LVGL application layer:
- Home screen with explicit time-sync-pending state (no invented clock values)
- Apps screen with unavailable modules clearly labelled
- System page with integration status
- Crown/key page cycling and LVGL touch-click navigation when the selected board
  provides the Actions input/display port

## Build status and target boundary

This is source code, not a firmware image. It has not yet been compiled against
the pinned Actions SDK in this repository. The SDK's public
`ats3089c_dev_watch` target is a development board and must not be treated as
the CMF Watch Pro 2 D398 target.

The D398-specific board port must be implemented and independently checked
against the owner's official 1.0.0.73 stock OTA before a device-target build or
OTA package can be considered. No bootloader, recovery or partition image is
generated by this application directory.

Do not flash a development-board output to the watch.
