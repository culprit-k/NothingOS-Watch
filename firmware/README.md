# Firmware

**No D398-ready firmware image exists here.**

The initial firmware milestone is a simulator-first LVGL shell and a reproducible Zephyr build for a supported Actions development target. A development-board build is not automatically compatible with the CMF Watch Pro 2.

Do not add flashing scripts or publish device-ready binaries until the D398 board profile, image format, boot validation, stock backup, and recovery gates in [docs/SAFETY.md](../docs/SAFETY.md) have been met.
